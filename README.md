# Employee Management System

A desktop application built with Java Swing and SQLite to manage employee information.

## Technologies

- Java (JDK 27)
- Java Swing
- SQLite
- JDBC (SQLite JDBC Driver)
- IntelliJ IDEA

## Features

- Display employee records in a table
- Add employee information
- Update employee information
- Delete employee records
- Refresh the employee list

## Database

The project includes `EmployeeProfile.db` as a sample SQLite database.

The database contains sample employee records and related information, such as positions and degrees.

## Setup and Run

1. Install a compatible JDK.
2. Clone or download this repository.
3. Open the project in IntelliJ IDEA.
4. Add `lib/sqlite-jdbc-3.53.4.0.jar` to the project dependencies.
5. Make sure `EmployeeProfile.db` is available in the application's working directory.
6. Run `Main.java`.

## Notes

- The application uses a local SQLite database.
- Database changes are stored in the local database file.
- This project was developed for learning Java Swing, JDBC, and SQLite.
